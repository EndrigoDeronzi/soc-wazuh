# Privacidade e limites
Todos os hosts, usuários, horários de incidentes e contagens são fictícios. O endereço 192.0.2.25 pertence à faixa destinada a documentação e não representa uma origem real do ambiente.

Não foram usados inventários, capturas, logs exportados, credenciais, tokens, certificados privados, domínios corporativos ou dados de colaboradores. O material foi criado para portfólio.

Os exemplos não comprovam uma detecção, uma implantação completa de SOC ou a execução de testes Wazuh. O fragmento XML foi verificado somente quanto à sintaxe; validação semântica e integração dependem de laboratório.

Ao adicionar novos arquivos, revise conteúdo, metadados e histórico Git. Use logs gerados em laboratório. Uma anonimização parcial de um log de produção pode preservar dados sensíveis em campos secundários.
